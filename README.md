# Analyzing Different Aspects in Generated Captions and Justifications from Multimodal LLMs

This repository contains the analysis pipeline for studying captions and justifications generated by multimodal LLM agents in the urban-scene perception setting. It is a follow-up analysis over persona-conditioned and no-persona annotations, focusing on how generated text behaves across sentiment, semantic similarity, topic structure, and convergence between demographic profiles.


## Setup

Requirements:

- Python 3.11+
- [uv](https://docs.astral.sh/uv/)
- Optional GPU support for faster transformer inference and embedding generation

```bash
git clone https://github.com/neemiasbsilva/analyzing-persona-effects-mllm
cd analyzing-persona-effects-mllm
uv sync
```
## Data

The data used in this repository consists of an annotated corpus derived from [mllm-persona-evaluation](https://github.com/neemiasbsilva/mllm-persona-evaluation). The corpus contains 59,708 records generated by 1,200 multimodal LLM agents annotating 50 urban scene images.

Each record includes:
1. A predicted sentiment label
2. A caption describing the image
3. One or more perception tags selected from a controlled vocabulary
4. A justification explaining the assigned sentiment

Example record:
```json
{
  "annotation_id": "p<prefix>_img_<image_id>_baseline",
  "persona_id": "<uuid>",
  "image_id": "<perceptsent_image_id>",
  "condition": "baseline",
  "raw_demographics": {
    "gender": "Female",
    "economic_status": "High income",
    "political_spectrum": "Progressive",
    "personality": "Empathetic"
  },
  "predicted_sentiment": "Positive",
  "predicted_perceptions": ["Green/Natural", "Lively"],
  "caption": "A tree-lined street with pedestrians walking on a sunny day.",
  "justification": "This kind of vibrant, green space is exactly what every neighborhood deserves."
}
```

The following files contain the annotations and metadata required to reproduce the experiments:

- `data/annotations_baseline.jsonl`: Persona-conditioned annotations generated by multimodal LLM agents.
- `data/annotations_no_persona_think.jsonl`: Baseline annotations generated without persona conditioning, with reasoning enabled.
- `data/annotations_no_persona_no_think.jsonl`: Baseline annotations generated without persona conditioning and without reasoning.
- `data/perceptsent-raw/`: Original PerceptSent metadata and annotations used for human ground-truth agreement analysis.

### Downloading the datasets

**Generated annotations** (`data/*.jsonl`) — download the released annotation files derived from [mllm-persona-evaluation](https://github.com/neemiasbsilva/mllm-persona-evaluation):

```bash

for file in \
annotations_baseline.jsonl \
annotations_no_persona_think.jsonl \
annotations_no_persona_no_think.jsonl
do
  curl -L -o "data/$file" \
  "https://raw.githubusercontent.com/neemiasbsilva/mllm-persona-evaluation/main/outputs/$file"
done

```

## Reproducing the Results

### Full pipeline

Run the main experiment script from the repository root:

```bash
./run_experiments.sh
```

This executes the cached analysis notebooks and then regenerates standalone figures with:

```bash
uv run python -m src.generate_figures
```

The script writes logs to `outputs/logs/` and figures to `figures/`.

To force recomputation of similarity caches:

```bash
./run_experiments.sh --force
```

### Individual notebooks

Each notebook can also be executed independently:

```bash
uv run jupyter nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.timeout=1800 \
    notebooks/03_text_similarity_captions.ipynb
```

Available notebooks:

- `notebooks/01_eda_captions_justifications.ipynb` - descriptive statistics for captions, justifications, sentiments, and perception tags.
- `notebooks/02_sentiment_analysis_justifications.ipynb` - sentiment inference with VADER/RoBERTa and agreement against model-predicted and human labels.
- `notebooks/03_text_similarity_captions.ipynb` - Sentence-BERT embeddings and cosine-similarity analyses for captions and justifications.
- `notebooks/04_topic_modeling_bertopic.ipynb` - BERTopic topic discovery over generated text.
- `notebooks/05_convergence_analysis.ipynb` - convergence tests across persona dimensions and profile groups.
